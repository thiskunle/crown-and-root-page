# Crown and Root page

The launch page for Crown and Root batana oil, operated by GramByte Technologies Inc. It's plain HTML and CSS, hosted on GitHub Pages.

- `index.html`: page content
- `styles.css`: page design
- `assets/`: logo and favicon

To update the live page, change these files and push to `main`. GitHub Pages republishes automatically.
